
# 📊 Demographic Data Analyzer (Pandas)

This project analyzes demographic data extracted from the 1994 Census database using **Python** and **Pandas**.

## 🎯 Project Overview
The objective is to answer specific demographic questions regarding age, education level, working hours, and income levels across different populations and countries.

## 🛠️ Tech Stack & Tools
- **Language:** Python
- **Library:** Pandas
- **Dataset:** Adult Census Income Dataset (UCI Machine Learning Repository)

## 📌 Key Insights Explored
- Demographic distribution by race and average age of male working population.
- Earnings ratio based on education level (Bachelors, Masters, Doctorate vs. lower education).
- Correlation between minimum weekly work hours and high income (`>50K`).
- Identification of countries with the highest percentage of high earners.
- Popular high-earning occupations in specific regions (e.g., India).
